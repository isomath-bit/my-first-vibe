# 고등학교 나이스(NEIS) 수행평가 성적 점검 시스템

> **학교 성적·수행평가 업무담당자를 위한 지능형 나이스 엑셀 일람표 점검 및 피드백 자동 생성 웹 애플리케이션**

## 🌟 주요 기능
1. **[Step 1] 다영역 루브릭 & 배점 조합 계산 엔진**
   - 영역별 만점, 기본점수, 0점 인정 여부 설정
   - 하위 채점 기준별 배점 등록 시 합산 가능한 모든 정당 배점 조합을 자동 계산
2. **[Step 2] 4세대 나이스 일람표 엑셀 업로드 & 자동 열 매핑**
   - 나이스에서 다운로드한 [강의실별 일람표] 엑셀 파일을 드래그 앤 드롭으로 즉시 분석
   - 일람표 내 영역명과 계획서 영역 간 지능형 자동 매핑
3. **[Step 3] 실시간 오류 검출 & 다각도 통계 리포트**
   - 배점 조합 불일치 오류, 공란(미입력) 누락자, 학적 변동자(전출/자퇴/유예 등) 자동 판정
   - 정상/오류 필터링 및 결과표 인쇄 기능
4. **[Step 4] 교과 담당 교사용 맞춤형 피드백 알림표 생성**
   - 쿨메신저/K-에듀파인 등 교내 메신저용 전달 문구 자동 서식 생성
   - 원클릭 클립보드 복사 지원

## 🔒 개인정보 보호 & 보안 원칙
- **Zero-Retention 브라우저 로컬 분석**: 업로드된 나이스 성적 엑셀 파일은 외부 서버나 데이터베이스로 전송되지 않으며, 사용자 컴퓨터의 브라우저 메모리 내에서만 처리됩니다.
- 창을 닫거나 새로고침하면 모든 학생 성적 데이터가 즉시 영구 파기됩니다.
